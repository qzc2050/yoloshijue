# 电离室正面质检规则（当前约定）

2026-09-22 与现场对齐。软件分析分两步：先按**理想外圈铜跑道**框住每一颗电离室，再在该腔上套五层模型判定渗墨/缺墨。

## 结构（从外到内）

```text
最外碳油 → 外圈铜环 → FR4 间隔 0.3 mm → 内圈铜环 → 内圈碳油 → 中心孔
```

理想模型：内外圈铜环表面都没有碳，两圈之间是干净的 0.3 mm FR4，内腔铺满碳油。

实际板件：碳会爬到内圈铜、外圈铜上，把可见金边咬得不规则。这是常见现象，**不影响功能，不判缺陷**。

同轴实拍：暗灰 = 碳油，金铜 = 露出的铜，两铜中间橄榄绿缝 = 间隔。最外碳油和内圈碳油几乎同色，靠位置区分。

中心孔（带柄小圆孔）是结构，不是缺陷。

## 这版只查两件事

### 1. 渗墨 — 隔离层不能有炭黑

只看整圈 **0.3 mm FR4 间隔**。位置不限：直线、弯头、靠近过孔都可能。

| 现象 | 判定 |
|---|---|
| 间隔里进了碳，缝被咬脏、咬窄、糊死 | 渗墨 |
| 间隔还在、一圈完整 | 合格 |
| 碳盖在外圈铜或内圈铜上（金边发虚、发黑、不规则） | 不管 |

### 2. 缺墨 — 内环中间不能缺炭黑

只看 **内圈铜以内的内腔碳油**。最外碳油不查。铜环本身有没有被碳盖住也不查。

| 现象 | 判定 |
|---|---|
| 内圈铜以内，该黑的地方露出白/绿 FR4（常见是贴着内圈铜的浅色牙边） | 缺墨 |
| 内腔一整块黑 | 合格 |

## 不管什么

- 最外碳油缺不缺
- **外圈铜上有没有碳**（可见外圈金边因此不规则，正常）
- **内圈铜上有没有碳**（可见内圈金边不规则，正常）
- 中心孔本身

## 软件流程

1. **得到电离室**：内部仍用外圈铜把腔框住，但画面上**不描外框**。
2. **描隔离层**：沿 0.3 mm FR4 间隔画**一条**中心线（不描外框、不描双边）。这才是渗墨要看的位置。
3. **套模型分析**：只查隔离层进碳、内腔缺碳。铜环上的碳不管。
4. **按相机原图做**：定位和分析都在采集分辨率上（海康 5472×3648）。界面缩放只改显示，不改判定。

## 认样

- **合格**：隔离缝一圈干净；内腔满黑。铜环上有碳、金边不完整也算合格。
- **缺墨（工厂手机图）**：内圈铜**里面**靠边露出白/绿。
- **渗墨（工厂手机图）**：0.3 mm 浅色隔离缝被碳咬进去；铜上的碳痂单独出现不算。
